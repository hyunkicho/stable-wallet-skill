# stable-wallet

스테이블코인 지갑 스킬이다. 이 저장소는 사용 규칙만 담는다. 잔액은 지갑 화면과 같은 장부에 있다.

운영자가 API 키와 이 저장소 주소를 에이전트에 주면, 에이전트는 KYA를 먼저 요청하고 멈춘다. 회원이 지갑에서 충전 금액과 결제 한도를 승인하면, 에이전트는 그 한도 안에서 결제한다.

## 앱이 할 일

- 승인 전에는 결제 버튼을 열지 않는다.
- 잔액, 남은 한도, 가맹점, 품목, 수량, 합계는 앱 화면에 보여 준다.
- 한도 안의 결제는 화면 확인 없이 진행한다. 한도를 넘는 금액은 막는다.
- 집금 주소는 결제 결과에 포함된 값만 보여 주고, 앱이 그 주소로 다시 보내지 않는다.

## 설치

이 폴더를 에이전트 스킬 디렉터리로 복사한다. `SKILL.md`가 진입점이다.

키는 앱이 이미 가진다. 이 스킬로 키를 발급하지 않는다.
