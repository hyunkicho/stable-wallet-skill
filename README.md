# stable-wallet

화면이 있는 앱에 붙는 스테이블코인 지갑 스킬이다. 이 저장소는 사용 규칙만 담는다. 잔액은 앱의 지갑 화면과 같은 장부에 있다.

## 앱이 할 일

- MCP 도구 `wallet_balances`, `wallet_topup`, `wallet_owner_auth`, `wallet_merchants`, `wallet_products`, `wallet_pay`를 등록한다.
- 잔액, 충전 금액, 가맹점, 품목, 수량, 합계는 앱 화면에 보여 준다.
- 충전과 결제는 그 화면에서 확인된 뒤에만 도구를 호출하게 한다.
- 주인 토큰은 앱 화면에 그리지 않는다. 도구가 보관한다.
- 집금 주소는 결제 결과에 포함된 값만 보여 주고, 앱이 그 주소로 다시 보내지 않는다.

## 설치

이 폴더를 에이전트 스킬 디렉터리로 복사한다. `SKILL.md`가 진입점이다.

키는 앱이 이미 가진다. 이 스킬로 키를 발급하지 않는다.
